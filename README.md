# Smart Agents – الوكيل الذكي (Starter Website + PWA)

This is a starter project for a bilingual Arabic/English responsive website and installable Progressive Web App.

## Included
- Arabic RTL and English LTR toggle
- Responsive home, services, about, portfolio, and contact sections
- PWA manifest and service worker
- Starter brand colors and a simple SVG brand mark
- Contact form prepares an email; it does not store or transmit submissions to a server

## Before publishing
1. Replace `REPLACE_WITH_COMPANY_EMAIL@example.com` in `app.js` with the real company email.
2. Replace `href="#"` social links in `index.html` with official social profile URLs.
3. Confirm the service list, descriptions, privacy notice, and legal terms.
4. Add a proper mascot/logo asset supplied or approved by the brand owner.
5. Test Arabic and English on mobile and desktop.
6. Publish through a static host with HTTPS. PWA installation requires HTTPS (or localhost for local testing).

## Free publishing path
- Create a GitHub repository and upload these files.
- Connect the repository to Cloudflare Pages, or use another static host.
- Use the free provider subdomain initially; connect a custom domain later when budget allows.

## Important
This starter is a front-end prototype. It has no customer accounts, database, secure file upload, payment processing, or backend order tracking. The generated mascot-like CSS illustration is a placeholder; use the approved brand mascot image for production.
